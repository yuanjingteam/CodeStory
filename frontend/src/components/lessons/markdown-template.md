# 题目 Markdown 模板规范

## 一、通用规则

### 1. 内容溢出处理
- 所有代码块自动启用横向滚动
- 长文本自动换行
- 图片限制最大宽度 100%

### 2. 样式层级
- 标题：h1 > h2 > h3（依次递减）
- 强调：加粗 > 斜体
- 代码：行内代码 < 代码块

---

## 二、题型模板

### 📝 选择题模板

```markdown
## 题目描述

以下关于 Python 变量的说法，**错误**的是？

## 选项

A. 变量不需要声明类型  
B. 变量名可以以数字开头  
C. 变量名区分大小写  
D. 变量可以随时改变类型

## 解析提示

> 思考：Python 变量命名规则是什么？
```

### 💻 编程题模板

```markdown
## 题目描述

编写一个函数，计算两个整数的和。

## 示例

**输入：**
```
a = 3, b = 5
```

**输出：**
```
8
```

## 要求

1. 函数名为 `add`
2. 接收两个参数
3. 返回结果为整数

## 代码模板

```python
def add(a, b):
    # 在此处编写代码
    pass
```

## 测试用例

| 输入 | 期望输出 |
|------|----------|
| 1, 2 | 3 |
| 10, 20 | 30 |
```

## 三、最佳实践

### ✅ 推荐做法

1. **结构清晰**：使用标题分隔不同部分
2. **重点突出**：用加粗强调关键信息
3. **代码规范**：始终使用代码块包裹代码
4. **适度引用**：用引用块表示提示或注意

### ❌ 避免做法

1. ~~过深的嵌套层级~~
2. ~~过长的段落（建议每段不超过 5 行）~~
3. ~~无意义的格式堆砌~~

## 四、特殊内容处理

### 代码块

\`\`\`python
def example():
    # 长代码自动滚动
    result = []
    for i in range(100):
        result.append(i ** 2)
    return result
\`\`\`

### 表格

| 参数 | 类型 | 说明 |
|------|------|------|
| a | int | 第一个数 |
| b | int | 第二个数 |

### 列表

有序列表：
1. 第一步
2. 第二步
3. 第三步

无序列表：
- 要点一
- 要点二
- 要点三

### 引用块

> 注意：这是重要的提示信息
> 
> 可以包含多行内容

## 五、样式预览

所有 Markdown 内容会通过 `MarkdownContent` 组件渲染，具有以下特点：

- ✅ 统一的字体和间距
- ✅ 代码块灰色背景 + 边框
- ✅ 引用块紫色左边框
- ✅ 链接紫色可点击
- ✅ 表格完整边框
- ✅ 响应式布局
