# 阶段 5：跨小节推荐与错题个性化复习

## 阶段定位

复用已经通过审核的检索层和掌握度事实，提供可解释的学习推荐与复习清单。

- 主计划依据：3.2、3.4、阶段 5、5.1。
- 前置依赖：阶段 1、3 审核通过。
- 后继解锁：阶段 6。

## 执行范围

1. 跨小节推荐：
   - 基于当前小节或薄弱知识点检索同课程相关内容。
   - 输出可点击的课程/小节目标、来源和相关度。
2. 错题个性化复习：
   - 结合 `answer` 的得分/错误状态和 `lessons_progress.mastery_level`。
   - 生成复习清单、重练建议及原因。
3. 冷启动：
   - 无学习数据时按课程顺序和难度提供基础推荐。
4. 权限：
   - 只返回用户有权访问且已发布的内容。
   - 不能通过推荐接口探测别人的答案、掌握度或私有课程。
5. 前端：
   - 在小节页和现有个人中心放置最小必要入口。
   - 显示来源/原因、加载、空、失败和冷启动状态。
6. 埋点：
   - 记录曝光、点击、复习开始和完成，供阶段 6 汇总。

## 禁止事项

- 不引入新的推荐模型或消息队列。
- 不修改掌握度事件矩阵。
- 不把模型生成的推荐当作授权依据。
- 不创建与现有设计语言竞争的新 dashboard。
- 不用少量在线点击数据宣称效果提升。

## 必须验证

- 有错题用户得到可点击且相关的复习项。
- 管理员编辑小节后，错题关联仍可追溯。
- 推荐结果包含可解释的来源或相关度。
- 跨课程、未发布和无权限内容不可见。
- 无答题记录的用户稳定走冷启动路径。
- 离线标注集 `Precision@5 ≥ 0.70`。
- 在线指标达到 100 次曝光后才报告点击率和完成率，并附样本量。
- RAG/推荐失败时页面回退基础推荐或给出非阻塞状态。

## 交付物

- 推荐/复习 service、route 和最小前端入口。
- 权限与冷启动测试。
- Precision@5 标注集及报告。
- 曝光/点击/完成事件定义与验证记录。

## 审核门禁

- 只复用阶段 1 的统一检索层，没有平行实现第二套向量查询。
- 个人学习数据的资源归属检查完整。
- 冷启动和降级路径可用。
- UI 遵循现有小节页与个人中心结构。
- 指标报告分母、样本量和失败案例清楚。
