# 阶段 1～3 人工审核工作表

运行 `pnpm run eval:prepare-human-review` 会基于仓库内固定 Qwen3 证据生成三份 CSV。
生成文件的所有 `human_*` 字段均为空，必须由独立审核者填写；Agent、模型或机器
指标不得回填到这些列，也不得删除失败样本。

- 阶段 1：40 条回答，审核回答中的课程 claim 是否被 evidence 支持；目标 `≥ 90%`。
- 阶段 2：50 道题，审核答案正确性和语义重复；目标正确率 `≥ 95%`、重复率 `≤ 5%`。
- 阶段 3：30 条评分，独立填写期望通过结论和百分制分数；目标一致率 `≥ 90%`、
  MAE `≤ 10`。

每行必须填写审核人、审核时间；不确定项写入备注且仍保留在分母。完成后的工作表
可能包含审核者信息，应存入受控验收附件；确认脱敏后再决定是否提交仓库。
